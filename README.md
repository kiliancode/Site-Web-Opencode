# Site-Web-Opencode

Site web vitrine généré par **Opencode** : la maison de cuisine fictive *L'Inédit*, Île Saint-Louis à Paris.

## À propos

L'Inédit est une maison de cuisine conceptuelle dirigée par la cheffe Amélie Roch, ancienne relieuse d'art. Le restaurant ne sert que **quatorze couverts, un seul service par soir**, et compose à chaque saison une « édition » unique, jamais réimprimée — un menu qui se lit comme un livre.

## Fonctionnalités

- **Sections thématiques** (folios) : La Table, Éditions, Le Rituel, Archives, Paroles, L'Adresse
- **Éditions saisonnières** : navigation entre Automne / Été / Printemps avec menus interactifs
- **Compteurs animés** : chiffres clés (couverts, services, temps au menu…)
- **Carrousel d'archives** et slider de témoignages
- **Modale de réservation** en 3 étapes (« Vol. I, II, III ») avec récapitulatif
- **Formulaire de contact** et newsletter
- **Plan intégré** OpenStreetMap
- Preloader animé, effets de hover, design éditorial
- Navigation responsive avec menu burger

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla, ES6)
- Google Fonts (Instrument Serif, Space Grotesk)
- OpenStreetMap (iframe)

## Démarrage

Ouvrez simplement `index.html` dans un navigateur, ou servez le dossier avec un serveur local :

```bash
python -m http.server
```

Puis accédez à `http://localhost:8000`.
